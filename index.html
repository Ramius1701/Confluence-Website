Where the streams meet

Confluence is a complete virtual world platform you run yourself: a grid server, a viewer and a voice service, built to work together and to feel like Second Life while staying OpenSimulator.

Three projects, one platform

Everything a grid needs

Each project lives in its own repository and can be used on its own. Together they give a grid owner the server, the client and the voice, with nothing to rent from anyone else.

Server

Confluence-OpenSim

An independent OpenSimulator fork with the grid portal, economy, search and moderation built in, not bolted on.

  • Native Web & Admin UI, Store and Marketplace
  • YEngine or Phlox scripting (LSL, OSSL, SLua)
  • ubODE, BulletSim or Jolt physics, per region
  • Moderation, abuse reports and display names
More about the server →
Client

Confluence Viewer

A modern viewer written in Rust with a Vulkan renderer, set up for OpenSim grids and the Confluence platform.

  • Multi-threaded loading and fast teleports
  • About half the video memory for the same textures
  • A clean modern UI, with legacy toggles
  • Multi-avatar login
More about the viewer →
Voice

Confluence-Voice

Spatial WebRTC voice for any OpenSim grid, as a single Windows program. No Vivox, no Linux, no Docker.

  • One .exe and one .toml file
  • Positional audio mixed for each listener
  • Works with Firestorm 7.1.10+ out of the box
  • Free and self-hosted, no per-user pricing

Why Confluence

Built on a few firm ideas

As close to Second Life as possible

Residents won't move to a grid that lacks what they expect. Behaviour is worked out from the best evidence available: Linden Lab's open-source SLua, what real viewers send and expect, and the Second Life wiki.

Still OpenSimulator

Open grids, Hypergrid, OSSL and grid-owner control stay. Official OpenSimulator remains the baseline, and its continuing work keeps being merged in.

Self-hosted, end to end

The web portal, economy, search and voice are part of the platform. A grid owner doesn't have to find, pay for and assemble separate services.

Optional by design

Anything that can reasonably be switched off can be. Grid owners choose what runs through their own configuration, and nothing is silently enabled.

Running live

Proven on a real grid

Confluence is developed against Casperia, a live grid with real residents, regions and content. Features are checked there with real viewers, not just a clean build.

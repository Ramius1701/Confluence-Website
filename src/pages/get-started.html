Confluence-OpenSim

Run your own grid

Every step of the setup guide is checked from a fresh clone on all six database-and-mode combinations, using only the example config files in the repository.

  1. Check the requirements

    The .NET 10 SDK and git. SQLite needs nothing else; for MySQL, MariaDB or PostgreSQL you need a running database server.

    Requirements

  2. Build it

    Clone the repository, run runprebuild.bat (or ./runprebuild.sh), then build the solution. Jolt and Phlox are built too, and stay off until you turn them on.

    git clone https://github.com/Ramius1701/Confluence-OpenSim.git
cd Confluence-OpenSim
runprebuild.bat
dotnet build OpenSim.sln --configuration Release

    Build steps · Linux and macOS

  3. Choose a database and a mode

    Standalone runs everything in one OpenSim.exe. Grid mode runs Robust.exe plus one or more region servers. Nothing is enabled for you: you copy each *.ini.example and edit it.

    Databases · Full setup guide

  4. Harden it before it goes public

    Lock down the services that run the grid before you open it to the internet.

    Security hardening

  5. Turn on what you want

    The web portal, economy and search are built in. Add the Phlox script engine, Jolt physics, the Marketplace or Experiences as your grid needs them.

    Phlox · Jolt · Marketplace · Experiences · All features

  6. Add voice

    The region side of WebRTC voice is already in the tree. Point it at a voice service.

    Set up Confluence-Voice

Confluence Viewer

Use the viewer

The viewer works on any OpenSim grid, not just ones running Confluence, and on Second Life.

  1. Download it

    Builds for Windows and Linux are on the downloads page; macOS is experimental.

    Download · Linux · macOS

  2. Add your grid

    Open the grid manager and add your grid with the login address it gives its residents. Hypergrid links and teleports to other grids work too.

    Most grids give a plain address such as http://grid.example.org:8002/, which sends your login unencrypted. If the grid also offers an encrypted https:// address (it may show it on its Get a Viewer page), use that one, exactly as given. Never mix the two: https:// with the plain port, as in https://grid.example.org:8002/, can't work and fails with a network error.

    Why encrypted logins matter

  3. Log in

    Each saved account shows as a card with its grid and last location. Several avatars, on several grids, can sit side by side.

  4. Keep it current

    On Windows the viewer checks for new versions in the background and offers them at login.

    How updates work · What the viewer can do

Confluence-Voice

Run voice for your grid

Confluence-Voice works with any OpenSimulator that has the os-webrtc-janus add-on, which upstream OpenSim and Confluence-OpenSim both include.

  1. Check what you need

    A Windows machine with a public IP and a DNS name, a TLS certificate, UDP ports 40000–40999 open, and TCP 9443 reachable from your region hosts only.

    Requirements

  2. Get the program

    Download a release or build it yourself, and put confluence-voice.exe in a folder of its own.

    Download · Building from source

  3. Configure it

    Run it once to create confluence-voice.toml, set your public IP and certificate, then open the firewall.

    Configuration · Firewall

  4. Point your regions at it

    Three things must be true in each region before a viewer will use WebRTC voice. Miss one and the result is silence.

    Configuring OpenSimulator

  5. Check it works

    Firestorm 7.1.10 and newer need no setup. If voice is silent, the troubleshooting guide walks through why.

    Checking it · Troubleshooting

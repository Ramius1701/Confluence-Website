The voice

Confluence-Voice

Spatial WebRTC voice for any OpenSimulator grid. One Windows program, one config file, and residents hear each other where they stand. No Vivox, no Linux VM, no Docker.

View on GitHub Quick start

Why it exists

Vivox has stopped taking new sign-ups for its free OpenSim voice service and has announced its end. Grids need a replacement they control before it stops. The existing WebRTC backend is built for Linux, with Docker or WSL for everyone else. Confluence-Voice gives Windows grid operators a native option.

Free and self-hosted

It costs only your own hardware and bandwidth: no account, no per-user pricing, and no outside service in the voice path.

Windows-native

A single confluence-voice.exe configured by one .toml file beside it. Download, edit one file, run.

Any OpenSim grid

Works with any OpenSimulator that has the os-webrtc-janus add-on, which upstream OpenSim includes. Not tied to Confluence-OpenSim.

Truly spatial

A separate mix for each listener, so voices pan and fade with distance the way residents expect.

Viewer-ready

Firestorm 7.1.10 and later work with no setup. Browser viewers can use the included reference client.

Secure by default

TLS is required, the region port takes an IP allow-list, and a TURN relay can be offered as a last resort for viewers behind strict networks.

How a call flows

The os-webrtc-janus add-on handles the region side. Confluence-Voice is what you point it at instead of a Janus gateway.

Quick start

Run the exe once. It writes confluence-voice.toml beside itself and exits. Set at least your public IP, then run it again.

public_ip = "203.0.113.10"
rpc_bind = "0.0.0.0:9443"
media_port_lo = 40000
media_port_hi = 40999
max_sessions = 900
tls_cert = "tls\\fullchain.pem"
tls_key = "tls\\privkey.pem"

What you need

  • Windows, with a public IP and a DNS name pointing at it
  • A TLS certificate (required, not optional)
  • UDP 40000–40999 open, which also caps concurrent sessions
  • TCP 9443 reachable from your region hosts only
  • The os-webrtc-janus add-on in your regions

Full steps, including starting it automatically, are in the README.

Confluence-OpenSim

An independent OpenSimulator fork, in the same vein as WhiteCore-Dev or Tranquillity: its own web and admin platform, native economy and search, and a full moderation stack, built into the server instead of left to add-ons.

What's built in

Confluence took the bet other forks deferred: build the portal, the economy and the search layer straight into the server, so a grid owner starts with everything they need.

Web & Admin UI

A grid portal hosted by Robust itself. Sign-up with starting-region and starter-look pickers, a home page with popular regions, events and classifieds, support tickets, a suggestion box, and an admin console. One login: your avatar name and in-world password.

Economy, Store & Marketplace

A native in-world economy with MoneyServer, a Store for regions and services, and a viewer-integrated DirectDelivery Marketplace.

Search & grid services

Built-in search for places, people, events, groups and classifieds, plus a grid status feed viewers can show in their Grid Status window.

Moderation & identity

Access control, abuse reports and display names, with one master account per email that can own and switch between several avatars.

Scripting

Expanded LSL and OSSL: Combat2, EEP environment scripting, pathfinding, Experience Tools, a bot and NPC framework. Run on YEngine (default) or Phlox, which adds SLua and keeps scripts' running state.

Physics & world

Choose ubODE, BulletSim or Jolt per region. Weather, map tiles, a region greeter, InWorldz/Halcyon archive loading and region-stability work.

Voice ready

The os-webrtc-janus voice modules are in the tree, ready to point at Confluence-Voice, with a hand-off for grids that still mix in Vivox regions.

Database

Full Unicode and emoji in every user-written text field on MySQL, with PostgreSQL and SQLite supported for grid and standalone setups.

Hardened control plane

Security hardening for the services that run a grid, documented in its own guide alongside the build, setup and testing guides.

Standing on many shoulders

Official OpenSimulator is the baseline, and its work keeps being merged in. Confluence began from OpenSim Continuum and has ported, by hand where it had to, the best of the wider ecosystem. Each port was checked against a real build first.

Grid owners can run it standalone or as a Robust grid, on Windows or elsewhere, and turn on only what they want through their own .ini files.
